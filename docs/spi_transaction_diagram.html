RACE 20 kHz write rate vs 10 kHz NSS rate

TIM1 fires twice as often as the Pi reads. That extra write lands mid-transaction.

DMA freezes on one buffer for the whole 100µs transaction (rearmed only at the NSS rising edge). The first ISR write each window safely lands in the idle buffer. The second write, ~50µs later, is still mid-transaction — spi_tx_write_idx has already flipped once, so the toggle sends it right back into the buffer DMA is actively shifting out. Fix: a third buffer, so the writer never has to re-enter a buffer DMA still holds.
